# Repositório para calcular pequenas operações de subtração, divisão, adição, multiplicação, potenciação e raiz quadrada.

## Para rodar o repositório em ambiente local, deve ter o Node.js baixado na máquina; 
## Depois abra um terminal e digite tsc -w;
## Abra outro terminal e acesse o diretório onde se encontra a saída de compilação /dist/js e execute node index.js para que os resultados sejam emitidos no terminal
